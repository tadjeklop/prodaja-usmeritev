AI asistent

Pomoč pri pisanju emailov, brifih in odgovorih s Claude API. Zahteva API ključ Anthropic.

Prva uporaba — nastavitev

Za uporabo asistenta potrebuješ Anthropic API ključ (console.anthropic.com). Ključ ostane lokalno v tvojem brskalniku, ne pošilja se nikamor razen direktno k Anthropicu.

Ključ je shranjen v localStorage tega brskalnika. Klikni „Pobriši" pod nastavitvami za odstranitev.

Hitre akcije

Začni s hitro akcijo ali napiši svoje sporočilo.

Kontekst za AI

Asistent samodejno dobi sistemski kontekst:

  • Si komercialist Interzero (EPR storitve, ne ERP)
  • Regija: Slovenija, Hrvaška, Srbija
  • Slog: profesionalen, konkreten, brez fluff besedila
  • Privzeti jezik odgovora: slovenščina (razen če eksplicitno drugače)

Uporaba: Vnesi konkreten kontekst (stranka, panoga, situacija), nato izberi hitro akcijo ali sam napiši vprašanje.
